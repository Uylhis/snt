Trois expériences pour comprendre les moteurs de recherche, les cookies et les droits sur les images. Les réponses se donnent dans Éléa.

Expérience 1 : le mini-moteur de recherche

Voici un mini-Web de 6 sites fictifs. Un mini-moteur de recherche fonctionne comme un vrai :

  • Indexation : son robot ne lit que les mots-clés de chaque page, rangés dans la balise <meta name="keywords">. Pour les voir : clic droit sur la page, puis Afficher le code source de la page.
  • Classement : parmi les pages qui contiennent le mot-clé recherché, il affiche en premier celle qui reçoit le plus de liens venant des autres sites (liens entrants), comme le PageRank de Google.

Ouvrez chaque site, notez ses mots-clés et les sites vers lesquels il fait un lien.

  • Les crêpes de Mamie Jo
  • Le blog du sarrasin
  • Chandeleur Info
  • Cuisine facile
  • Vélo en Bretagne
  • Le Journal du Port

Un internaute tape la requête crêpes. À vous de prévoir les résultats !
